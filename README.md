# HyperHDR-Android

Screen capture client for [HyperHDR](https://github.com/awawa-dev/HyperHDR), targeted at Android TV (API 28+).

Status: **in development.** See `docs/superpowers/specs/2026-05-02-hyperhdr-android-grabber-design.md` for the spec and `docs/superpowers/plans/` for the implementation plans.

## What it does

Streams the Android TV screen to a HyperHDR instance over the FlatBuffer wire protocol (NV12). HyperHDR drives the LEDs (Hyperk, HyperSerial, Adalight, etc.).
